# EXIT IRR Simulator

Standalone interactive IRR calculator for Dubai real estate investments, prepared by **EXCEED REAL ESTATE L.L.C.**

## Live URL

https://exceed-realestate.github.io/IRR-simulator/

## Features

- 8 property presets (Ritz-Carlton, One Za'abeel, Serenia Living, Six Senses Palm 3BR/4BR, ORLA Dorchester, Palm Jebel Ali, Emerald Hills) — or any custom inputs
- Bilingual (日本語 / English) toggle
- Live IRR, sale-price, HKD-denominated net proceeds
- 3-scenario comparison (off-plan flip, post-handover short, long-term hold)
- Initial outlay breakdown (DLD, Trustee, agent, mortgage registration, broker fee, etc.)
- Annual holding-period cash flow with mortgage amortisation
- EXIT proceeds breakdown including DLD transfer, NOC, loan payoff
- Cumulative cash flow chart
- Property brochure modal with PDF downloads
- 30-second interactive guided tour
- Print-to-PDF preview (landscape, 2-page layout, preserves brand colors)

## Files

- `index.html` — main simulator (single-file, no build step)
- `exceed_logo.jpg` — company logo
- `brochures/*.pdf` — property brochures referenced by the simulator

open index.html
